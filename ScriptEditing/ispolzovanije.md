## Текстовые варианты выбора (opcode 0x15)

`asb_tool.py import` после импорта реплик автоматически запускает `choice_text.py` для всех созданных ASB, включая `startup`. Изменять `build_patch.bat` не требуется: его обычная команда импорта уже включает этот этап.

- Источник русских подписей: `choice_translations.json` (20 уникальных пунктов).
- Читаемая таблица: `choice_translations.md`.
- Варианты не нужно добавлять в диалоговые листы `new_tv.xlsx`: у них отдельный словарь.
- Пустые строки выбора сохраняются без изменений.
- Неизвестная непустая подпись останавливает сборку с именем ASB и адресом команды; сначала добавьте перевод в словарь.
- Переводы кодируются тем же RU_F, что и реплики; автоперенос для однострочных кнопок отключён.
- Длины команд и строк обновляются, абсолютные переходы 4/5 пересчитываются.
- Повторная обработка уже переведённой папки безопасна.

Отдельный запуск для распакованных ASB:

```powershell
py -3.12 choice_text.py ./script_patched
```

Проверки:

```powershell
py -3.12 -m unittest test_asb_tool test_choice_text
```
